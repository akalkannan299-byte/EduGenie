# EduGenie – Project Report

## Abstract
EduGenie is a Google Gemini powered learning assistant developed using FastAPI and a browser-based frontend. It combines question answering, concept explanation, quiz generation, summarization, and learning path recommendations in one application.

## Objectives
1. Provide AI-assisted educational answers.
2. Explain difficult concepts at different learner levels.
3. Generate practice quizzes.
4. Summarize educational content.
5. Recommend a structured learning path.
6. Demonstrate API-based Generative AI integration.
