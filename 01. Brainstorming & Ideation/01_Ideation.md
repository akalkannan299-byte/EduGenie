# EduGenie – Brainstorming & Ideation

## Project Title
EduGenie: Google Gemini Powered Learning Assistant

## Problem Statement
Students often need quick explanations, question answering, summaries, quizzes, and structured learning guidance in one place. EduGenie is designed as a learning assistant that brings these activities together through a simple web interface.

## Proposed Solution
Build a FastAPI-based educational assistant integrated with Google Gemini. The system provides:
- Question & Answer
- Concept Explanation
- Text Summarization
- Quiz Generation
- Personalized Learning Path Recommendations

## Target Users
- College students
- Beginners learning technical subjects
- Learners who want quick explanations and practice

## Main Idea
A learner selects a task, enters a topic or text, and EduGenie sends the request to the appropriate backend module. The backend uses Gemini to generate the educational response and returns it to the web interface.

## Expected Benefits
- One interface for multiple learning tasks
- Beginner-friendly explanations
- Interactive quiz practice
- Structured learning recommendations
- API-based modular architecture
