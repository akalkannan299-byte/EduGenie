# EduGenie – Presentation Slide Content

## Slide 1 – Title
EduGenie: Google Gemini Powered Learning Assistant

## Slide 2 – Problem
Students often use separate tools for explanations, summaries, questions and practice.

## Slide 3 – Proposed Solution
EduGenie combines these educational tasks in one AI-powered application.

## Slide 4 – Objectives
- Q&A
- Explanation
- Summarization
- Quiz generation
- Learning recommendations

## Slide 5 – Technology Stack
- FastAPI
- Python
- Google Gemini
- HTML/CSS/JavaScript
- Jinja2
- Uvicorn

## Slide 6 – Architecture
Browser → FastAPI → Learning Modules → Gemini

## Slide 7 – API Endpoints
- POST /qa
- POST /explain
- POST /quiz
- POST /summarize
- POST /learn/recommendations

## Slide 8 – Testing
Input validation, API tests, application startup checks and live Gemini integration testing.
